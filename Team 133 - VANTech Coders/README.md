# Suswad Cafe Smart Canteen System

Team: VANTech Coders  
Members: Tanvi, Vasavi, Arya, Neeraja  

## Description
A Flask-based web application to manage canteen orders efficiently using Queue (FCFS).

## Features
- Customer interface to place orders
- Order status tracking
- Queue position display
- Canteen admin panel (password protected)
- Order processing system
- Sales report

## Tech Stack
- Python (Flask)
- HTML, CSS
- DSA: Queue, Dictionary, List
